# SQL Sales Analysis Project

This project analyzes sales data using SQL to generate business insights such as revenue trends, top customers, and product performance.

##  Project Objective
To perform sales data analysis using SQL by creating a structured database with 30+ records and applying analytical queries.

##  Tools Used
- MySQL
- GitHub

##  Concepts Covered
- SELECT Statements
- GROUP BY
- HAVING
- ORDER BY
- Aggregate Functions (SUM, COUNT, AVG)
- Window Functions (RANK)

##  Key Insights
- Identified top-selling products
- Calculated monthly revenue trends
- Found highest revenue-generating customers
- Analyzed category-wise sales performance
